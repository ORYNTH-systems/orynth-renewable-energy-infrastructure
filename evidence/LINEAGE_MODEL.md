# EMAH — Lineage Model

## Status

**EMAH-ARCH-09 / ACCEPTED**

Lineage preserves the historical relationship among EMAH / AHME records.

---

# 1. Governing Chain

Where applicable, the evidence lineage may preserve:

`Object`
→
`Transition`
→
`Authority / Admissibility References`
→
`Command`
→
`Execution Attempt`
→
`Execution Outcome`
→
`Observed Physical Effect`
→
`Effect Residual`
→
`AHME Residual`
→
`Recoverability`
→
`Recovery`
→
`Requalification`
→
`Reintegration`
→
`Regenerative Return`

This is historical lineage.

It is not an authority chain.

---

# 2. Non-Erasure

Later successful recovery does not erase earlier execution or effect history.

Therefore:

**Recovery != Lineage Reset**

**Reintegration != Lineage Reset**

---

# 3. Branching

Lineage may branch.

For example:

- one execution may produce multiple effect observations;
- one residual may undergo multiple recovery attempts;
- one recovery may yield multiple downstream records.

Lineage therefore must not assume a single linear chain.

---

# 4. Missing Link

A missing lineage element must remain explicit.

Therefore:

**Missing Lineage != Preserved Continuity**

---

# 5. Historical Identity

Historical linkage does not imply persistent physical particle identity.

Therefore:

**Record Continuity != Persistent Physical Energy Identity**
