# AHME — Recovery / Return Boundary

## Status

**EMAH-ARCH-08 / ACCEPTED**

AHME governs the regenerative-return domain within EMAH.

It begins where a bounded energy-domain residual, depleted condition,
impaired condition, or otherwise recovery-relevant state has been identified.

It does not erase the prior execution, effect, or historical state.

---

# 1. Governing Chain

AHME preserves:

**Residual != Recoverable**

**Recoverable != Recovered**

**Recovered != Requalified**

**Requalified != Reintegrated**

**Reintegrated != Authorized for renewed consequential use**

---

# 2. Recovery / Restoration Separation

Recovery does not imply restoration of prior historical state.

Therefore:

**Recovery != Restoration**

**Recovered State != Historical Non-Occurrence**

**Recovered State != Prior State Restored**

A recovered system may be usable without being historically identical to
its pre-residual condition.

---

# 3. Historical Persistence

The occurrence that produced the residual remains part of system history.

Therefore:

**Recovery != Historical Erasure**

**Reintegration != Historical Erasure**

**Renewed Availability != Historical Erasure**

AHME must preserve linkage to:

- originating object;
- originating transition;
- originating execution;
- observed physical effect;
- effect mismatch or residual where applicable;
- recovery process;
- requalification;
- reintegration.

---

# 4. ARCH-07 Relationship

ARCH-07 distinguishes:

`EnergyEffectResidual`

from:

`EnergyResidual`

AHME consumes that distinction.

An effect residual may contribute to identification of a recovery-relevant
condition, but it does not automatically become an AHME residual object.

Therefore:

**EnergyEffectResidual != EnergyResidual**

---

# 5. IPT Boundary

IPT may evaluate preservation, degradation, continuity, and recoverability.

AHME owns energy-domain recovery / return semantics.

Therefore:

**IPT Recoverability Evaluation != AHME Recovery Execution**

and:

**Recoverability Assessment != Recovery Process**

---

# 6. Authority Boundary

No AHME return state creates execution authority.

Therefore:

**Recovered != Authorized**

**Requalified != Authorized**

**Reintegrated != Authorized**

Renewed consequential use must pass the accepted EMAH authority and
admissibility architecture.

---

# 7. Forward Boundary

ARCH-08 defines recovery / return architecture.

It does not define complete evidence and provenance requirements.

Those remain reserved for:

**EMAH-ARCH-09 — Evidence + Provenance**
