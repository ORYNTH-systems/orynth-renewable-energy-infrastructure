# AHME — Reintegration Model

## Status

**EMAH-ARCH-08-P01 / CANDIDATE**

Reintegration represents governed return of requalified energy or capacity
into a declared EMAH energy-system context.

---

# 1. Governing Distinction

**Requalified != Reintegrated**

---

# 2. Candidate States

ARCH-04 defines:

- `REC_REINTEGRATION_PENDING`
- `REC_REINTEGRATED`

---

# 3. Reintegration Preconditions

Candidate structural preconditions include:

1. recovery completed to the required scope;
2. requalification successful;
3. target energy-system context identified;
4. interface compatibility established;
5. current authority/admissibility separately satisfied where required;
6. unresolved material conditions absent.

---

# 4. Reintegration / Availability

Reintegration does not automatically imply physical availability for every
future action.

Therefore:

**REC_REINTEGRATED != PHY_AVAILABLE by default**

---

# 5. Reintegration / Authority

Reintegration does not create authority.

Therefore:

**REC_REINTEGRATED != AUTH_VALID**

**REC_REINTEGRATED != ADM_ADMISSIBLE**

**REC_REINTEGRATED != Execution Authority**

---

# 6. Historical Continuity

Reintegration must not erase the prior residual/recovery chain.

Therefore:

**Reintegration != Historical Reset**
