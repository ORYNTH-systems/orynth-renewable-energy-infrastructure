# EMAH — Proof of Block Interface

## Status

**EMAH-ARCH-11-P01 / CANDIDATE**

## External Owner

Proof of Block

## Consumed Semantics

Proof of Block provides governed refusal evidence / reconstruction for
execution prevention.

UAA remains responsible for blocking / execution-prevention semantics.

## Governing Distinctions

**Execution Block != Proof of Block**

**Proof of Block != Blocking Authority**

**Proof of Block != Execution Authority**

**Refusal Evidence != Authority**

## EMAH Use

EMAH may bind Proof of Block evidence to:

- transition identity;
- authority/admissibility result;
- execution gate;
- blocked execution state;
- affected energy object;
- relevant timestamp / boundary.

## Ownership Rule

EMAH does not redefine Proof of Block.
