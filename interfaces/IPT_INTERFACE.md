# EMAH — IPT Interface

## Status

**EMAH-ARCH-11-P01 / CANDIDATE**

## External Owner

IPT

## Consumed Semantics

IPT may contribute evaluation of:

- preservation;
- degradation;
- residual capacity;
- recoverability;
- continuity;
- reconstruction distinctions.

AHME owns energy-domain recovery / return semantics.

## Governing Distinctions

**Remaining Capacity != Recoverability**

**Recoverability != Recovery**

**Recovery != Restoration**

**Identity-Relevant Preservation != Identity Continuity**

**Energy Recovery != IPT Recoverability Evaluation**

## Interface Rule

An IPT recoverability assessment may inform AHME.

It does not automatically:

- authorize recovery;
- admit recovery;
- establish recovery completion;
- requalify recovered energy;
- reintegrate energy.

## Ownership Rule

AHME does not redefine IPT preservation or recoverability semantics.
