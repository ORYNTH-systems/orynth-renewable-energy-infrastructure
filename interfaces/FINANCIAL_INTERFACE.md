# EMAH — Financial Infrastructure / UES Interface

## Status

**EMAH-ARCH-11 / ACCEPTED**

## External Owner

ORYNTH Financial Infrastructure / UES

## Financially Owned Semantics

Financial Infrastructure retains ownership of:

- economic effect;
- partial economic effect;
- settlement;
- compensation;
- reversal;
- financial finality;
- financial reconciliation.

## EMAH-Owned Semantics

EMAH retains ownership of:

- physical energy state;
- physical transition;
- physical execution;
- physical consequential effect;
- physical partial effect;
- physical effect residual;
- AHME energy recovery / return.

## Governing Distinctions

**Physical Effect != Economic Effect**

**Physical Delivery != Financial Settlement**

**Physical Partial Effect != Financial Partial Effect**

**EnergyEffectResidual != Financial Residual**

**Payment != Energy Delivery**

**Settlement != Authority**

**Compensation Cannot Self-Authorize**

## Interface Rule

A financial result may reference a physical EMAH result.

It cannot replace that physical result.

Similarly, an EMAH physical result cannot silently determine the financial
result.

## Ownership Rule

Interface exchange does not transfer semantic ownership.
