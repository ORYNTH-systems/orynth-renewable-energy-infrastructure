# EMAH — EIP Interface

## Status

**EMAH-ARCH-11-P01 / CANDIDATE**

## External Owner

EIP

## Consumed Semantics

EMAH consumes execution-time rule identity and continuity semantics where
relevant to governed energy transitions.

## Governing Distinctions

**Energy Continuity != Rule Identity Continuity**

**Physical Object Continuity != Execution Rule Continuity**

**Current Energy State != Current Rule Identity**

## Interface Use

EIP may support determination that the rule or execution-policy basis applied
at execution time is the expected rule identity.

EMAH supplies energy-domain transition context.

## Ownership Rule

EMAH does not redefine generic EIP continuity semantics.
