# EMAH — Execution / Effect Failure Classes

## Status

**EMAH-ARCH-14-P01 / CANDIDATE**

### EMAH-TF-EXE-001
Command presentation is treated as execution attempt.

### EMAH-TF-EXE-002
Execution attempt is treated as execution completion.

### EMAH-TF-EXE-003
Execution completion is treated as proof of observed physical effect.

### EMAH-TF-EXE-004
Execution records substitute for physical-effect evidence.

### EMAH-TF-EXE-005
Blocked execution is classified as failed execution.

### EMAH-TF-EXE-006
Block and abort states are collapsed.

### EMAH-TF-EXE-007
Temporal sequence is treated as sufficient causal attribution.

### EMAH-TF-EXE-008
Missing observation is treated as observed zero effect.

### EMAH-TF-EXE-009
Under-effect and over-effect residuals are collapsed into one untyped value.

### EMAH-TF-EXE-010
Multi-dimensional physical effect is collapsed into a scalar without an
explicit aggregation rule.
