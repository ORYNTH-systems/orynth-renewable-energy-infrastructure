# EMAH — Obligation / Interface Failure Classes

## Status

**EMAH-ARCH-14 / ACCEPTED**

### EMAH-TF-OBL-001
Obligation is treated as authority.

### EMAH-TF-OBL-002
Obligation is treated as admissibility.

### EMAH-TF-OBL-003
Obligation state is collapsed into financial settlement state.

### EMAH-TF-OBL-004
Partial obligation satisfaction is represented as full satisfaction.

### EMAH-TF-OBL-005
Obligation residual is collapsed into EnergyEffectResidual.

### EMAH-TF-OBL-006
Obligation residual is collapsed into EnergyResidual.

### EMAH-TF-OBL-007
Compensation self-authorizes consequential action.

### EMAH-TF-OBL-008
Recovery silently erases an outstanding obligation.

### EMAH-TF-OBL-009
Settlement silently erases a physical-domain obligation.

### EMAH-TF-OBL-010
Object transfer is treated as automatic obligation transfer.

### EMAH-TF-INT-001
Interface existence is treated as inheritance.

### EMAH-TF-INT-002
Inheritance is treated as semantic ownership.

### EMAH-TF-INT-003
Reference to an external primitive is treated as ownership transfer.

### EMAH-TF-INT-004
Dependency is treated as ownership transfer.

### EMAH-TF-INT-005
Need for an external primitive is used to justify silent EMAH ownership or
duplication.
