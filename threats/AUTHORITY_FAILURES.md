# EMAH — Authority / Admissibility Failure Classes

## Status

**EMAH-ARCH-14 / ACCEPTED**

### EMAH-TF-AUTH-001
Capability is treated as sufficient authority.

### EMAH-TF-AUTH-002
Authority validity is treated as sufficient admissibility.

### EMAH-TF-AUTH-003
Historical authority is treated as current authority without revalidation.

### EMAH-TF-AUTH-004
Prior authorization is treated as present execution eligibility.

### EMAH-TF-AUTH-005
Credential, key, token, or access possession is treated as authority.

### EMAH-TF-AUTH-006
Physical availability is treated as execution authority.

### EMAH-TF-AUTH-007
Evidence is treated as authority.

### EMAH-TF-AUTH-008
Obligation existence is treated as authority.
